# Lagoon One

One-take procedural film for this sentence:

> Ultra-realistic seaplane flying over Bora Bora, landing on the water, and letting passengers off.

56 seconds. The floatplane comes in over the reef, flares, lands, taxis to a pontoon, and four passengers step ashore. Three.js only. No photo plates of the plane, the people, or the island.

Drag to look around the current shot. Chapter chips jump to Approach, Reef, Flare, Splash, Taxi, and Ashore. Space pauses. Replay starts the take again.

## Run

```bash
npm install
npm run dev
```

The scene is `src/lagoon/` (about 1,300 lines). The page shell is `src/routes/index.tsx`.
